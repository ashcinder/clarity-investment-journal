# 澄明 · 投资手账

私人投资记录应用，基于 React 19、TypeScript、Vinext、Cloudflare D1 和 Sites 身份验证。账本保存在数据库中，以登录用户隔离，不依赖浏览器本地存储。

## 已实现

- 六个页面：资产总览、账户与资产、定投计划、资金流水与投资手记、收益分析、偏好设置。
- 四个方向：Crypto 现货、美股 ETF、合约网格、人民币基金。预置两个独立现货账户；支持新增、编辑、归档、恢复账户，以及删除没有流水/计划的空账户。
- 初始本金为现货 1,200 USD 和网格 20 USD；SPY、白酒和其他基金不虚构初始余额。1,200 USD 暂放现货 A，B 初始为零，可通过同币种转账调整分配。
- Crypto 每月 60 USD、SPY 每月 100 USD、白酒每个中国交易日 20 CNY、其他基金每交易日 10 CNY。
- 每日/每周/每月定投，设置金额、时间、日期、开始日期，暂停、跳过、撤销跳过、确认执行。月末 29–31 日在短月按月末处理。日计划休市跳过，周/月计划顺延，未知年份停止生成并提示更新。
- 中国市场使用上海时区，Crypto 使用北京时间，美股使用纽约时区（含夏令时）。页面每分钟刷新待确认状态。
- 投入、取出、估值、分红/收入、手续费，可编辑、删除、补记历史；同币种内部转账原子保存。
- 资产分配环图、总资产与净投入曲线、累计盈亏曲线、原币账户收益率。
- USD/CNY 同时汇总，参考汇率在线更新、手工调整、历史流水汇率留存。
- 投资手记、账户筛选、流水搜索与分页、JSON 全量导入/导出、兼容 Excel 的 CSV 导出。
- 乐观版本锁防止多窗口覆盖，服务端结构和金额校验、来源检查、用户隔离。
- 响应式浅色工作台、移动端导航、键盘焦点、对话框与减少动态效果支持。

## 本地运行

Node.js 22.18+（推荐 Node.js 24/26）与 npm。

```bash
npm ci
npm run db:local
npm run dev -- --hostname 127.0.0.1
```

打开终端输出的 Local URL。Sites 插件在 loopback 开发环境提供本地登录，并设置仅用于开发的 Cookie。生产环境由 Sites 提供真实身份，API 始终要求登录。

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

API 集成测试只允许 loopback，依赖正在运行的开发服务器；它会创建临时手记、验证持久化与冲突保护，然后删除临时手记：

```bash
CLARITY_TEST_ORIGIN=http://127.0.0.1:3001 node tests/api-smoke.mjs
```

数据库结构在 `db/schema.ts`，迁移在 `drizzle/`。通过 `npm run db:generate` 生成后续迁移。生产由 Sites 在部署前执行迁移。请不要修改已经应用的迁移文件。

## 收益口径

- 原币账户盈亏 = 当前估值 + 累计取出 − 累计投入。
- 简单累计投入回报率 = 盈亏 ÷ 累计投入。未做资金时间加权或年化；零投入时显示“—”。
- 收入增加余额、费用减少余额；绝对估值记录会覆盖该时点的账户价值。更新估值应填写总市值/总权益，而不是收益金额。已包含在估值中的收益或费用不要重复入账。
- 组合投入/取出使用各笔流水保存的汇率，当前资产使用最新适用参考汇率；因此汇总盈亏包含汇率影响。内部转账从组合投入/取出中排除，仍计入账户层面的转入/转出。
- 归档账户仍参与全部资产与收益计算，其计划暂停。减少账户不等于凭空移除其资产。
- 曲线只从第一条真实记录开始；无估值日期沿用最近记录，不伪造历史收益或行情。历史汇率不足时沿用最早参考值，图表中明确提示。

## 数据来源与当前边界

- 初始汇率 6.7157 来源于 2026-09-04 Frankfurter USD/CNY 响应；可在设置更新。
- [Frankfurter API](https://frankfurter.dev/)：每日参考汇率，不是成交汇率。
- [上交所 2026 年休市公告](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)：CN 2026 年交易日历。
- [NYSE 交易日历](https://www.nyse.com/trade/hours-calendars)：US 2026–2028 年节假日。只判断交易日期，未建模盘中时段、临时停市、提前收盘和单只基金暂停申购。
- 未配置实际币种数量、基金代码、交易所/券商授权。因此当前通过手动录入**账户总估值**自动计算收益；没有自动抓取资产持仓或价格。设置页明确说明。
- 定投为计划和记账，不是自动扣款或下单；到期后确认实际金额才会入账。无关闭页面后自动执行、交易或推送通知的服务。
- CN 未核验年份会停止基金计划生成，可根据正式公告在设置导入整年休市日期。基金特殊申购限制以基金公司公告为准。
- 上限：100 个账户、100 项计划、10,000 条流水、5,000 篇手记；备份限 4 MB。记录以 JSON 账本存入单个 D1 行，适用于个人投资日志。并发保存发生冲突时拒绝覆盖并提示刷新。

## 验证

21 项领域测试覆盖初始资金、现金流、估值、手续费、转账、双币种汇率损益、归档、回溯曲线、市场节假日、调休周末、未知年份、月末顺延、夏令时和重复确认。API 测试覆盖未登录拒绝、保存后读取、版本冲突、非法金额、跨来源请求，以及实时汇率响应。

此轮未执行浏览器视觉/点击验收。WebMCP 仅在支持 `document.modelContext` 的浏览器注册摘要读取及打开记账表单两个工具；当前环境未完成 WebMCP 合约测试，普通界面不依赖它。

Lint 校验第一方应用代码；脚手架原样提供的 `components/ui` 和 `hooks` 作为上游组件库排除。
